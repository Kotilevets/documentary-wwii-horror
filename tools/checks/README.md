# Проверки одной командой

Скрипты на Python 3.10+ без сторонних пакетов. Путь к Godot 4.7.2 — `--godot ПУТЬ` или переменная `GODOT`, иначе `godot` из `PATH` и обычные места установки (winget, `/Applications/Godot.app`, `/usr/bin`). Проект — `--project ПАПКА`, по умолчанию тот, в котором лежит эта папка. Godot эту папку не импортирует (`.gdignore`). Подробности — `docs/ARCHITECTURE.md`, раздел «Проверка».

## Три прогона

```
python -I tools/checks/run_suites.py
python -I tools/checks/run_suites.py --suites units
python -I tools/checks/run_suites.py --fresh
```

Юниты, сквозной прогон и проходимость по очереди, у каждого свой срок. Прогон зелёный, только если вышел сам с кодом 0, напечатал итог и в его выводе нет ни одной ошибки скрипта или разбора, а до первой проверки — и никакой другой строки `ERROR:`. `--fresh` — как после клонирования: последний коммит (`git archive HEAD`, без незакоммиченного) во временную папку, импорт, потом прогоны там; данные пользователя (`user://`) этих прогонов тоже ложатся во временную папку. Код выхода — число красных шагов.

## Каталоги поломок

```
python -I tools/checks/mutate.py --list
python -I tools/checks/mutate.py spotted --dry
python -I tools/checks/mutate.py spotted
python -I tools/checks/mutate.py spotted A21 A30
```

Каталог (`mutants/*.py`) — прогон, на котором поломки должны попасться, и сами поломки: «файл, старый текст, новый текст». Формат описан в начале `mutate.py`. Сначала прогоняется хороший код: контроль должен быть зелёным. Потом каждая поломка: `CAUGHT` — попалась; `SURVIVED` — проверки её не видят; `KNOWN` — известно, что выживает, и документы объясняют почему; `BROKEN` — код не разобрался или прогон не уложился в срок. Тронутые файлы после каждой поломки и в конце возвращаются побайтно; их хорошие копии лежат ещё и в `.godot/mutate_backup/`. Если прогон убили снаружи, следующий запуск не начнётся, пока `python -I tools/checks/mutate.py --restore` не вернёт файлы. Код выхода — `SURVIVED` + `BROKEN`.

`--dry` запускается без Godot и проверяет, ложится ли ещё каждая правка на код. Правка, которая не ложится, — ошибка каталога: её обновляют или помечают `stale` с причиной.

Пока идёт `mutate.py` или `run_suites.py`, файлы игры не править и второй Godot не запускать: прогон меняет файлы на время поломки, и вторая копия Godot помешает первой.
